🚀 INICIO RÁPIDO (5 pasos)

1. Instalar
   cd Media-Tecnica-Frontend
   npm install

2. Configurar
   Crear .env con:
   VITE_API_URL=http://localhost:8000

3. Backend
   Verificar que está corriendo en :8000

4. Ejecutar
   npm run dev

5. Acceder
   http://localhost:5173
   admin@test.com / admin123
